P38: 3. Software y frameworks
P39: La siguiente tabla resume las tecnologías seleccionadas para el desarrollo del sistema AFRISAN y su justificación técnica, en coherencia con la arquitectura definida para el proyecto.
P40: Componente
P41: Tecnología propuesta
P42: Justificación
P43: Frontend móvil
P44: .NET MAUI (.NET 8)
P45: Permite desarrollar una aplicación multiplataforma para Android/iOS con una sola base de código. Se integra con Camera.MAUI / ZXing.Net.MAUI para lectura QR y con SQLite para operación offline.
P46: Frontend web
P47: Blazor WebAssembly (.NET 8)
P48: Mantiene el ecosistema .NET en la capa cliente web y consume la API REST mediante HTTPS/JSON.
P49: Backend / API REST
P50: ASP.NET Core Web API (.NET 8)
P51: Framework seleccionado para implementar servicios REST, reglas de negocio, autenticación y acceso seguro a los datos.
P52: Autenticación
P53: JWT + ASP.NET Core Authentication
P54: Permite autenticación stateless para la API, control de acceso por roles y transmisión segura sobre HTTPS/TLS.
P55: ORM / acceso a datos
P56: Entity Framework Core 8
P57: ORM seleccionado para el mapeo objeto-relacional, consultas y migraciones sobre PostgreSQL.
P59: 4. Base de datos y almacenamiento
P60: Recurso
P61: Tecnología propuesta
P62: Justificación
P63: Base de datos central
P64: PostgreSQL 16 / Supabase Cloud
P65: Motor relacional robusto y compatible con Entity Framework Core. Supabase se utiliza como servicio administrado para alojar PostgreSQL en la nube.
P66: Almacenamiento local offline (móvil)
P67: SQLite (sqlite-net-pcl)
P68: Persistencia local embebida para registrar información sin conexión y sincronizarla posteriormente con la API.

P102: 7. Estimación referencial de costos
P103: La siguiente tabla entrega una estimación referencial de costos mensuales o anuales asociados a los servicios cloud considerados. Estos valores son aproximados y deberán confirmarse con cotizaciones actualizadas durante la etapa de desarrollo.
P104: Ítem
P105: Costo estimado
P106: Observación
P107: Azure App Service + Supabase (nivel gratuito/básico)
P108: $0 — $20.000 CLP/mes aprox.
P109: Costo referencial sujeto al nivel de uso; ambos servicios disponen de opciones de entrada adecuadas para desarrollo académico.
P110: Power BI (licencia Pro, si se requiere publicar/compartir)
P111: $0 — $13.000 CLP/mes por usuario aprox.
P112: Power BI Desktop es gratuito; Power BI Pro puede requerirse para compartir el dashboard con AFRISAN.
P113: Dominio o subdominio propio (opcional)
P114: $0 — $15.000 CLP/año aprox.
P115: Opcional; puede utilizarse un subdominio gratuito del proveedor cloud durante el desarrollo.
P116: Cuenta de desarrollador (Google Play / App Store, si se publica)
P117: $0 — $99 USD/año aprox. (App Store)
P118: Solo aplica si se decide publicar la app móvil en tiendas oficiales; no es requisito para el alcance académico.
P119: Para un proyecto de alcance académico, se espera que la mayoría de los servicios pueda operar dentro de los niveles gratuitos o de entrada de cada proveedor, salvo que AFRISAN requiera capacidades adicionales (por ejemplo, licencias Power BI Pro para compartir el dashboard con múltiples usuarios).
