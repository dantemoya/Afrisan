
# Sprint 1 — AFRISAN

## Estado
Sprint cerrado.

## Objetivo del Sprint
Establecer la base técnica y arquitectónica del proyecto AFRISAN antes de iniciar el desarrollo funcional de las historias de usuario.

## Actividades completadas

- [ARQ-01] Definir arquitectura base de AFRISAN.
- [ARQ-02] Definir tecnologías y arquitectura de 3 capas.
- [ARQ-03] Elaborar diagrama de arquitectura.
- [BD-01] Diseñar modelo inicial de base de datos.
- [RN-01] Definir reglas de negocio y validaciones principales.
- [CFG-01] Configurar repositorio GitHub AFRISAN.
- [CFG-02] Crear estructura base Afrisan.Web y Afrisan.Api.
- [DOC-01] Documentar arquitectura y decisiones técnicas.
- [REV-01] Preparar arquitectura para revisión docente.

## Resultado del Sprint

Durante el Sprint 1 se estableció la base técnica necesaria para continuar con el desarrollo de AFRISAN.

Se definió una arquitectura de tres capas compuesta por:

- Afrisan.Web — Blazor WebAssembly.
- Afrisan.Api — ASP.NET Core Web API.
- PostgreSQL / Supabase — persistencia de datos.

También se establecieron las principales reglas de negocio, la estructura inicial del repositorio y la documentación técnica del proyecto.
