## Objetivo del Sprint

Consolidar y validar las funcionalidades principales relacionadas con la gestión y trazabilidad de cilindros de refrigerante.

Durante este Sprint se priorizan las siguientes historias de usuario:

- HU-01 — Asociación QR, Orden de Trabajo y despacho.
- HU-02 — Pesaje de salida en bodega.
- HU-08 — Retorno y balance de masa.

---

## Historias de usuario priorizadas

### HU-01 — Asociación QR, OT y despacho

Gestionar la identificación de cilindros mediante código QR, su asociación a una Orden de Trabajo y su posterior proceso de despacho, manteniendo la trazabilidad de cada movimiento.

### HU-02 — Pesaje de salida en bodega

Registrar y validar el peso de salida de los cilindros antes de su despacho, considerando las reglas de negocio definidas para el proceso.

### HU-08 — Retorno y balance de masa

Registrar el retorno de los cilindros, su peso de retorno, el historial de movimientos y la información necesaria para realizar el balance de masa.

## Estado técnico actual

AFRISAN cuenta actualmente con una base técnica desarrollada sobre:

- Blazor WebAssembly.
- ASP.NET Core Web API.
- PostgreSQL / Supabase.
- Entity Framework Core.
- Arquitectura de tres capas.

El repositorio contiene avances técnicos previos relacionados con la gestión de cilindros y la comunicación entre la aplicación web, la API y la base de datos.
